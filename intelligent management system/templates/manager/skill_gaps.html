Strategic Skill Deficit Detection

Rule-based capacity intelligence comparing active incomplete task skill requirements against qualified workforce headcount.

How Skill Gaps Are Calculated
Active Demand: The number of uncompleted tasks requiring a specific technical skill.
Available Supply: The number of active employees possessing that verified skill.
If Demand > Supply or Demand ≥ 1 with 0 available staff, the system flags a Skill Gap for executive hiring or training prioritization.
